Thêm {{< term "toán tử tìm kiếm" >}} vào câu tìm kiếm để thu hẹp kết quả:

| Gõ | Để nhận |
| --- | --- |
| `"cụm từ chính xác"` | Trang có đúng các từ đó theo đúng thứ tự |
| `site:example.com mẹo` | Kết quả chỉ từ một trang web |
| `jaguar -car` | Kết quả không chứa từ đứng sau dấu trừ |
| `báo cáo filetype:pdf` | Chỉ file PDF (hoặc `docx`, `xlsx`, `pptx`) |
| `intitle:review` | Trang có từ đó trong tiêu đề |

Kết hợp chúng: `site:reddit.com "battery drain" -iphone`.

{{< details title="Ví dụ tìm kiếm" closed="true" >}}
- `"error 0x80070005" site:microsoft.com`: tìm mã lỗi, chỉ trên trang của Microsoft.
- `mẫu ngân sách filetype:xlsx`: bảng tính làm sẵn.
- `intitle:review "galaxy a56" -sponsored`: bài đánh giá, bỏ các bài tài trợ.
{{< /details >}}
